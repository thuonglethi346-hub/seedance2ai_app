# Seedance2AI Site Guide

Seedance2AI is a public website for AI video and image generation workflows.

Use this skill when the user needs help with:

- finding the right page on `seedance2ai.app`
- understanding which tool page matches a generation task
- comparing Seedance2AI video-model pages at a high level
- routing someone to pricing, showcase, or core tool pages
- explaining common creator use cases for the site

## Core pages

- Home: `https://www.seedance2ai.app/`
- Seedance tool: `https://www.seedance2ai.app/tools/seedance`
- Pricing: `https://www.seedance2ai.app/pricing`
- Showcase: `https://www.seedance2ai.app/showcase`

## Video model pages

Use these when the user asks for a specific model family:

- Seedance: `https://www.seedance2ai.app/tools/seedance`
- Veo 3: `https://www.seedance2ai.app/tools/veo-3`
- Sora 2: `https://www.seedance2ai.app/tools/sora-2`
- Kling 3.5: `https://www.seedance2ai.app/tools/kling-3-5`
- Wan 2.5: `https://www.seedance2ai.app/tools/wan-2-5`

If the user only says "AI video generator", start from the homepage or the Seedance page.

## Image tool pages

Use these when the user asks for image generation or image editing:

- GPT Image 2: `https://www.seedance2ai.app/tools/gpt-image-2`
- Ideogram: `https://www.seedance2ai.app/tools/ideogram`
- Kling Image: `https://www.seedance2ai.app/tools/kling-image`
- Background Remover: `https://www.seedance2ai.app/tools/background-remover`
- AI Image Upscaler: `https://www.seedance2ai.app/tools/ai-image-upscaler`

## Routing rules

1. If the user wants the broadest overview, send them to the homepage.
2. If the user wants Seedance-specific video generation, send them to the Seedance page.
3. If the user asks about plans or cost, send them to pricing.
4. If the user wants examples or inspiration, send them to showcase.
5. If the user mentions a specific model name, send them directly to that model page.

## Common use cases

- Generate short AI videos from prompts
- Turn still images into motion clips
- Compare multiple AI video model pages from one site
- Explore AI image generation and enhancement workflows
- Check pricing before trying generation tools

## Response style

- Prefer direct page routing over long explanations.
- Mention the exact page URL when it is helpful.
- Keep comparisons high level unless the user asks for a deeper breakdown.
